# 使用前置条件与当前适用范围

更新日期：2026-10-10。本文说明现有小红书试验版的实际使用条件，不代表已完成真实账号或手机验收。

## 安装之前先判断是否适合

**这是已有小红书内容读取能力的离线扩展，不是安装后即可使用的小红书离线客户端。** `xhs-offline-skill` 由本项目开发，通过 Red Skill 分发；它不是小红书官方提供的内容读取或离线缓存接口。

如果你已经有可以正常读取小红书内容的 Agent / MCP、脚本执行环境和文件交付能力，可以试用本工具整理与导出离线包。如果目前只有手机上的小红书 App，或一个仅能聊天的 Agent，安装本 Skill 并不能自动补齐这些能力。现阶段不适合向普通用户承诺“装好就能一键缓存两小时小红书”。

## 准备真实内容需要什么

| 前置条件 | 具体要求 | 容易误解的地方 |
| --- | --- | --- |
| 执行环境 | 实际执行主机可运行 Node.js 22.12+，可读写数据与导出目录；完整保留 Skill 脚本、适配器、阅读器和资源文件 | 手机聊天界面不代表程序在手机本机执行；宿主能发现 Skill 不代表能执行它 |
| 真实内容来源 | 已有兼容的小红书工具，能成功返回推荐列表与笔记详情；当前适配 `list_feeds`、`get_feed_detail`，或上游对应的本机 REST 接口 | 本 Skill 不捆绑、不自动安装或启动内容服务；安装成功不代表来源已接通 |
| 登录与网络 | 上游工具完成自身的正常登录，并在它实际运行的环境中能访问内容和图片资源 | 手机 App 已登录，不会自动授权另一个 Agent、浏览器或远程主机；一个分享链接也不等于已取得完整内容 |
| 宿主集成 | 已有 MCP 连接需按接入说明注入调用能力，或使用实际执行主机上的本机 REST 服务 | 本机 `127.0.0.1:18060` 指执行脚本那台主机，不是手机或另一台电脑；REST 不通也不能直接否定另一种已连接的 MCP 来源 |
| 可用性验证 | 先获取一条真实笔记并生成小包，核对正文、图片、评论覆盖情况和失败信息 | 服务进程启动、端口开放、健康检查或工具列表存在，都不能代替真实内容读取成功 |

现有上游是独立的第三方项目，并不是 Red Skill 商店提供的官方内容接口。安装、登录、浏览器依赖和网络排障属于上游准备工作，不能算作本 Skill 已自动解决。若依赖被安全软件拦截，应停止执行并核验来源与文件；不能仅因它是已知项目的组件就断言误报，也不应把关闭保护或添加排除项当成常规使用前提。

接入方式见 [integration.md](../xhs-offline-skill/references/integration.md)，上游项目见 [xpzouying/xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp)。

## 文件怎样真正到达手机

| 执行位置 | 交付条件 |
| --- | --- |
| 电脑准备 | 文件通过已有传输方式送到手机；二维码接收要求手机与电脑同网，传输期间电脑保持运行且局域网访问可用 |
| 远程 Agent 准备 | 宿主需要真实的附件发送或文件下载能力；远程磁盘路径、localhost 地址和“附件已生成”的文字不等于手机可下载 |
| 手机本机 Agent 准备 | 只有该宿主确有程序执行、真实内容来源和本地文件保存能力时才成立，不能按 Agent 品牌或聊天客户端外观推断 |

阅读端需能从手机本地文件入口运行 HTML 脚本、显示图片；保存阅读进度还需该入口允许本地存储。系统文件预览可能只能显示静态页面，移动文件或更换入口也可能影响进度恢复。

出发前必须在实际手机上完成一次：**保存文件 → 关闭在线预览 → 开启飞行模式 → 从本地重新打开 → 检查正文、图片、评论、翻页与搜索 → 关闭重开检查进度。** 下载成功、电脑浏览器测试和模拟手机尺寸不能代替这一步。已有完整阅读文件不需要继续运行 Agent、Node 或 MCP。

详细流程见 [手机交付说明](../xhs-offline-skill/references/mobile-delivery.md)。

## 当前承诺与验证边界

- 已发布 V1.1.0 面向图文、图片及上游实际返回的评论/回复，不支持视频缓存。视频开发候选的测试不等于已发布版本具备该能力，也不等于真实小红书视频获取成功。
- 评论是准备时取得的快照，不保证包含全部评论或回复；未获取不能解释为没有评论。
- 当前推荐接口没有已适配的分页约定，一批内容不足目标时会返回 `partial`。指定时长是准备目标，图文时长是规则估算，不能保证获得足量内容或个人实际阅读时长。
- Mock 是演示数据，不是实际小红书内容。真实来源失败时不会静默替换成 Mock。
- 截至本次更新，真实小红书账号获取、Android/iPhone 本地入口及飞行模式完整流程仍未验收。自动测试验证的是相应模块与构造场景，不证明普通用户已经能顺利完成整个流程。

## 为什么调整方案方向

本次试用发现，最费力的环节是获取真实内容和建立可用环境，而不是生成阅读页。Skill 可以携带脚本并组织工作流，但不会自动获得平台账号权限、补齐宿主工具或保证手机交付。

后续先围绕用户实际目的与便利性验证“取得真实内容 → 保存到手机 → 断网重新打开”的最小流程，再选择载体。平台 Skill 可以继续作为辅助入口和分发渠道，不再预设它是飞机离线阅读的核心载体。现有内容打包、评论快照和阅读器模块仍可复用；独立网页、浏览器扩展或 App 的可行性需另行验证，换载体不会自动解决内容来源。

Red Skill 与小红书 App 内“小工具”也不同。官方 Red Skill 安装说明提供技能安装流程；小工具官方能力清单则规定不支持网络请求，列出的原生接口主要用于发布笔记、保存图片和写临时文件。不能因为来自平台商店或运行在 App 内，就推断可以读取推荐流、评论或账号登录态。
